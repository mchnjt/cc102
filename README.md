## 🚀 TechStart Heads-Up

**TechStart** is the section of this repo that stores guides for setting up a development environment on different devices, so you can get coding before the activity even begins.

Before starting any activity, make sure you have:

- [ ] A code editor (e.g., VS Code)
- [ ] Git installed
- [ ] A GitHub account
- [ ] The tools required by the activity (listed in each activity's folder)

Setup guides by device:

| Device / OS | Guide |
|-------------|-------|
| Windows | `techstart/windows.md` |
| macOS | `techstart/macos.md` |
| Linux | `techstart/linux.md` |
| Android / Chromebook / Others | `techstart/others.md` |

> 💡 Stuck on setup? Open an issue and tag it `techstart` so others can help.

## 🌿 Branches

This repository uses branches to keep things organized.

| Branch | Purpose |
|--------|---------|
| `main` | Stable, reviewed content. Start here. |
| `techstart` | Environment setup guides |
| `activity/<number>-<topic>` | Work for a specific activity (e.g., `activity/01-intro`) |

**Switching branches:**

```bash
git clone https://github.com/mchnjt/cc102.git
cd cc102
git branch -a              # list all branches
git checkout <branch-name> # switch to a branch
```
